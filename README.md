A one-page newspaper front page summing up Thursday 26 November 2026 in a single 1024x1024 image: three lead stories (EU leaders clash over the 1.6tn budget and Ukraine loan, the storm that postponed Macy's 100th parade, the Bank of Korea rate hike to 3.25%), three medium stories (Asian markets rally, oil climbs on Hormuz fears, US soldiers march in Vilnius), a world map of the day's datelines, and a DATE CHECK box naming the 25 November stories that are not Thursday's news. All reports as of 06:00 GMT.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The entrypoint copies the pre-rendered `entry.png` into the output directory and self-checks it: complete valid PNG, exactly 1024x1024, under one mebibyte. Stdlib only, no network, deterministic.
